# LoopFinder 现场速查卡（打印放工具包里）

> 详细步骤见《[新手使用手册](使用手册.md)》。这张卡只记"遇到什么 → 点什么"。

---

## 出门前检查

- [ ] 笔记本已充电
- [ ] USB 转网口转接头 + 1 根网线（去教研室）
- [ ] USB 转 Console 线（去机房）
- [ ] 已知：交换机 IP、SNMP 团体名、Console 密码（去机房）
- [ ] 软件打开过，演练模式跑过一遍

**打开软件：**
- **Mac**：直接双击应用程序里的 **`LoopFinder`**；如果要去教研室测环路，打开后点顶部黄色条里的 **「🔐 一键开启本机抓包权限」** 输开机密码即可（去机房查 SNMP / Console 不用输密码）。
- **Windows**：直接双击 **`LoopFinder.exe`**（弹窗点「是」）。去教研室实时抓包需提前装过一次 Npcap。

## 现象 → 操作

### 🏫 某个教研室断网 / 很卡 → 第 1 页
1. 笔记本插到教研室小交换机的空口
2. 网卡选 **🔌有线** → **▶ 开始监测**，打开右上角 **🔊 声音雷达**
3. 红色 **🚨 确认环路**？
   - 先看「私接小路由器清单」有没有红色**私接非法**的 → 按品牌型号找到它
   - 没有 → 右侧 **✂️ 二分法拔线**：
     - 数网线（**不算笔记本那根**）→ 填数字 → **开始二分法**
     - **拔红色、插蓝色、绿色已排除的全部插回去** → 等 5 秒
     - 叮咚变绿点 **✅**，还在报警点 **🚨** → 重复，直到显示"第 X 号网口"

### 📶 电脑显示已连接但上不了网，IP 是 192.168.x.x → 第 1 页
1. 清单右上角填学校 DHCP 服务器 IP → **存白名单**（只需一次）
2. **▶ 开始监测** → **📡 扫私接路由**
3. 红色**私接非法**那行 = 私接路由器（看品牌、型号）
4. 找到后：墙上网线改插路由器 **WAN 口**，或拿走

### 🏢 整层 / 整栋楼都卡 → 第 2 页（能连上交换机时）
1. **🚀 自动逐跳顺藤摸瓜**：填汇聚/核心交换机 IP，MAC 留空 → **🚀 自动逐跳定位末端端口**
2. 看最后一个红框的端口和房间 → 去那个房间做"教研室断网"流程
3. 不会自动追？用 **🔍 单台交换机双采样深度扫描**，排第一的端口有 **↘ 追踪下级** 就点它

### 🔌 网全瘫了，连不上交换机 → 第 3 页（在机房）
1. Console 线插交换机 `CONSOLE` 口 + 笔记本 USB
2. **关掉 SecureCRT / PuTTY 等终端软件**
3. 串口点 **↻** 选 🔌 那项，波特率 `9600`，品牌 `自动识别`
4. **⚡ 一键双采样找广播源头口**
5. 看 **🚨 广播源头灌入口** 那行：
   - LLDP 列有交换机名 → 去那台交换机重复
   - 显示"直连末端" → 查台账找到房间

### 📋 终端里的命令输出看不懂 → 第 3 页最下方
复制输出 → 粘贴到「交换机日志一键解析」→ **🔍 一键解析**

## 颜色速记

| 第 1 页大横幅 | 第 2 页端口方块 | Console 方向判定 |
|---|---|---|
| 🚨 红 = 确认环路 | 🔴 红 = 重点查 | 🚨 源头灌入口 = **就是它** |
| ⚠️ 黄 = 有私接路由/偏高 | 🟠 橙 = 预警/串了小交换机 | ⚡ MAC 漂移涉事口 = 一起查 |
| 🟢 绿 = 正常 | 🟢 绿 = 正常 | ⚪ 受害转发口 = **可排除** |
| ✅ 已断开 = **刚拔的那根就是** | ⬜ 灰 = 没插线 | |

## 处理完

1. 右上角 **🖨️ 打印报告** → 另存 PDF 存档
2. 给问题网线贴标签
3. 提醒老师：路由器插 **WAN 口**，网线别两头插同一台交换机

## ⚠️ 记住

- 拔线前跟老师打招呼
- 软件对交换机**只看不改**；需要关端口止血，找有权限的管理员操作，事后记得恢复
